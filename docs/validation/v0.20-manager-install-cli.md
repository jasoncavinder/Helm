## Diagnostic Correction

The failure exposed a misleading `cargo_build_failed` classification because
Cargo wraps an offline download failure in `failed to compile`. Exact native
offline/cache-miss signatures now produce `cargo_offline_cache_miss`, owned by
local configuration, before generic compilation classification. Guidance names
`CARGO_NET_OFFLINE` and `net.offline`; Helm does not enable networking, alter
dependencies, retry automatically or label the entire Mac offline.

The corrected CLI reproduced the same native failure with one isolated dependency
temporarily held outside its cache and restored afterward. Its durable task logs
contain `cargo.offline_cache_miss` before CLI exit, with no installed binary.
After restoring the cache and removing the offline override, that same corrected
CLI installed 1.24.0, detected its isolated path and removed it through Helm again
(fixed-diagnostic database tasks 1-3).
All seven mirrored locales and task-guidance lookup are updated. Existing true
compiler, DNS and endpoint classifications remain distinct.

## User Contract

The local brief offers an optional repair review. Opening it only reads the
prepared service's proposal and saved receipts. It does not execute a repair,
acknowledge the experience, or activate ordinary discovery.

The finite mise repair shows the saved path, the exact executable to check,
the preference-only scope, the bounded local version command, no requested
download/elevation, and the absence of automatic rollback. Confirmation is
separate and explicit. Back returns to metadata-only observation without changes.
No eligible plan is a valid read-only outcome, not a failed installation.

The service/core owns eligibility, token binding, execution and verification.
Swift strictly decodes the known capability envelope and displays its result;
it does not invent a replacement repair or infer manager readiness.

After confirmation the UI always reads back the durable ledger. A successful
transport reply alone is insufficient. A missing or timed-out reply may still
have committed, so the UI never automatically resends the mutation. It accepts
only one new matching receipt, with agreement if an apply receipt was returned.
Missing/conflicting readback shows that the result is unavailable and the saved
selection may have changed. Review Saved Results reads only; it does not retry.

Verified, failed and unverified receipts remain distinct. None claims that
packages are healthy or the default PATH now chooses the checked executable.
Stored history remains visible inside the guarded startup review, including
after an interrupted previous launch. General Activity/history and CLI setup
presentation are not added by this slice.

The user can return to the brief or explicitly continue after a result, including
a failed/unverified result. Continuing still performs the independent durable
experience acknowledgment before ordinary runtime activation. In-flight repair
and readback phases cannot acknowledge or activate. Session generations reject
late callbacks; duplicate apply callbacks cannot request duplicate readbacks.

All new text is mirrored in all seven locales. The brief's local-only disclosure
now describes the observation itself, not an incorrect claim that no command
has ever run after an optional repair.

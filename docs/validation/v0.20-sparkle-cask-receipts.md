# External Sparkle Homebrew Receipt Exclusions

## Scope

This denial-only follow-up starts from reviewed/merged #637 at `65421dae`.
It does not enable adoption or updater execution. The production adoption
provider remains `nil` and all native target observations still require authority
resolution. Keep #606/#607/#608 open and preserve Open App.

The standard-prefix Homebrew reference scan had two gaps relevant to future
adoption: case-sensitive destination comparison and no installed-receipt
observation when a moved-app reference is missing. The new observer supplements
the existing scan with fixed per-token `.metadata/INSTALL_RECEIPT.json` and
`config.json` reads. A matching supported receipt app declaration is a competing
manager claim even without a version directory or symlink. No Ruby, cask DSL,
installer artifact, shell, brew command or current environment configuration is
evaluated. Existing group-writable manager metadata may deny, never authorize.

## Native Contract

- Each receipt is at most 256 KiB, each config at most 64 KiB, and all receipt/
  config bytes across both prefixes share a 4 MiB cap. Each receipt has at most
  512 artifact entries; the existing 10,000-entry Caskroom traversal bound remains.
- Opens refuse symlinks in every component. Existing metadata directories must
  be directories; fixed metadata files must be nonempty regular files. FIFOs,
  dangling aliases, unreadable files and oversized files fail closed.
- `uninstall_artifacts` app entries use source basename unless a target rename
  is present. Absolute targets and relative targets are normalized lexically;
  relative targets use saved `explicit > env > default` appdir precedence.
- A saved config must have dictionary-valued `default`, `env` and `explicit`
  layers. Missing appdir uses Homebrew's fixed `/Applications` default; supplied
  appdirs must be absolute. Home-relative targets/configuration, malformed app
  arguments and missing saved configuration for app declarations are unsupported,
  not guesses based on the helper's current HOME, working directory or options.
- All destination operations are in-memory with explicit file-URL hints. They
  do not probe unrelated volumes, expand symlinks or infer directory status.
  A full app path or a declared destination inside that app is a denial; equal
  basenames in different application directories and prefix collisions are not.
- Reference/destination comparison uses fixed-locale case folding and canonical
  Unicode composition. Setapp location exclusions use the same component-bound
  rule. This can conservatively overexclude on case-sensitive volumes and never
  establishes path identity or permission.
- Exact receipt/config bytes and metadata/file identities join the manager
  snapshot compared around target signature validation. Claim-preserving raw
  changes invalidate that observation. This is not an atomic manager lock or a
  reservation against changes after observation.
- `homebrewCaskReceipt` and diagnostic destination paths are retained in native
  evidence; the ABI uses the existing Homebrew exclusion bit. Rust still reports
  `otherManager`, never standalone or user-adopted permission from an exclusion.

Missing receipts and legacy/null/empty artifact declarations remain unresolved.
Timestamped cask JSON/Ruby, nonstandard prefixes, receipt-less custom installs,
destination aliases and other unsupported manager evidence remain outside this
slice. Neither `unresolved` nor absence of these new exclusions is a complete
ownership assertion. Do not enable `ownershipComplete` from that result.

## Source Basis

Homebrew 7.0.6's installed VM sources and actual receipt/config files were read
without invoking brew. `Cask::Tab` retains uninstall artifacts in the fixed
receipt; `Cask::Config` defines saved layer precedence; `Artifact::Relocated`
defines source basename and target rename behavior. Reference paths:

- [Homebrew tab](https://github.com/Homebrew/brew/blob/7.0.6/Library/Homebrew/cask/tab.rb)
- [Homebrew config](https://github.com/Homebrew/brew/blob/7.0.6/Library/Homebrew/cask/config.rb)
- [Homebrew relocated artifact](https://github.com/Homebrew/brew/blob/7.0.6/Library/Homebrew/cask/artifact/relocated.rb)

The VM's Docker cask JSON is `{}`, while its installed receipt retains `Docker.app`
and its saved config records `/Applications`. The implementation deliberately
does not treat an empty saved definition as an empty ownership result.

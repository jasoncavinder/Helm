# Inspector Diagnostic Localization

## Scope

Owner QA on 2026-09-30 found English text in the mounted manager Inspector after
changing the app language: the metadata-mismatch banner and explanation,
manager category, and inconsistent-state detection reason.

The diagnostic UI already resolves localization keys at render time and receives
the Control Center locale revision. The six non-English catalogs still contained
English values for the metadata-only diagnostic cluster and inconsistent reason.
Two categories, Container/VM and Security/Firmware, also fell through to raw
English because neither Inspector category switch handled them.

The correction translates the diagnostic cluster and matching manager-card warning
in all six supported non-English
locales, fills Hungarian detection-reason gaps, and uses one render-time category
resolver for the production and research Inspectors. Category labels describe
manager families; branded manager names such as Mac App Store and Homebrew remain
unchanged. Both canonical and bundled locale trees stay synchronized.

No detection, repair, eligibility, ordering, persistence, or locale-observation
policy changes. In particular, language changes must not reset selection,
expanded diagnostic details, repair consent, or receipt state.

# v0.20 uv Multi-Package Plan Certification

Checkpoint: 2026-09-28. Bounded native CLI evidence on the disposable macOS 27
arm64 VM, with uv 0.12.9 and 0.12.18 and Python 3.14.7. This is not signed GUI,
public-index, all-version or supported-platform certification.

`scripts/tests/uv_vm_cli_plan.py` reuses the checked-in inert-wheel generator.
It requires explicit disposable-environment opt-in, absolute executables and a
private new root for each run. No inherited credentials, production databases,
tool stores or shell configuration are passed to the child processes. Python
downloads and network resolution are disabled; wheel-only installs use local
generated packages. Evidence is retained even on failure.

## Contract

Each passing run records 20 commands, including four native fixture/version
commands and 16 Helm CLI commands:

- Seed two range-constrained tools at 1.0 and one native exact-pinned tool at 1.0.
- Publish local 1.1 wheels; verify two cached candidates and a two-step Plan.
- Helm-pin one eligible tool and verify one Plan step remains, without changing
  any native receipt. Unpin before execution.
- Run both updates and verify persisted 1.1 versions. The first update must not
  invalidate the second tool's scope. The native exact pin remains at 1.0.
- Preserve receipt requirements, Python, entrypoints, source order and options.
  uv can save an identical `find-links` source twice when combining global and
  receipt options; only exact repeats are normalized for this comparison. The
  untouched native-pinned peer must retain byte-identical receipt contents.
- Refresh to an empty Plan, run it again as a no-op, verify unchanged versions,
  completed tasks and SQLite integrity.

The public uv Plan preview currently lists package identities, not Cargo's
`candidateVersion`/`reviewedScope` JSON fields. This test checks uv candidates and
identifiers through `updates list` and the existing runtime binding, rather than
claiming a new preview schema or a durable cross-command review token.

## Reproduce

Execute only in a disposable macOS guest, using Python 3.11 or newer:

```sh
python3 scripts/tests/uv_vm_cli_plan.py \
  --helm /absolute/path/to/helm \
  --uv /absolute/path/to/uv \
  --artifacts /absolute/path/to/disposable-evidence \
  --confirm-disposable-environment
```

The existing `uv_vm_cli_lifecycle.py` now locates the same checked-in fixture by
default; `--fixture` remains available for an explicit relocated copy. Its shared
process runner reaps only the owned process group on timeout or interruption,
with a bounded TERM wait before KILL. Seven safety tests cover explicit opt-in,
OS boundaries, private environment, narrow receipt comparison and cleanup races.
CI runs those tests without invoking Helm/uv or installing packages.

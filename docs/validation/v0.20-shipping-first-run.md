## Preserved Contract

- Fresh installs and pre-v0.20 profiles, including legacy-completed profiles
  without previous-version metadata, use the same `wayfinder-v0.20` marker.
- Required legal acceptance is persisted and read back. Existing current GUI
  acceptance remains valid; introducing the experience does not change terms.
- Before explicit continuation, prepared storage supplies bounded local file
  evidence, cached facts and saved preferences, not live manager health.
  No ordinary detection, polling, catalog refresh or scheduled updater check
  starts before activation. Schema preparation is not a read-only database open.
- Optional finite mise preference repair retains separate review, explicit
  confirmation, core revalidation and durable verified/unverified receipts.
  Relaunch or a lost reply never automatically reapplies a repair.
- Use Helm Now discloses resumption of ordinary saved behavior, persists and
  rereads acknowledgment, then starts network-aware discovery once per service.
  Unknown/offline network state defers network work. This is not permission to
  install/update packages, modify shell setup, or elevate privileges.
- Closing before continuation does not acknowledge. Acknowledged relaunches,
  later RCs, stable and patches skip the introduction without resetting language,
  manager enablement, pins, update settings/channel, consent, receipts or history.
  The independent legacy CLI onboarding flag is neither reset nor backfilled.
- Existing connection/controller generation fences and failed-state retry
  handling are unchanged. No migration, FFI wire schema or updater design changes.

The full generalized persisted setup session/network-consent/CLI parity design
remains v0.21 scope. This activation ships only the bounded implemented contract
above, not synthetic plans, progress, readiness scores or general repair claims.

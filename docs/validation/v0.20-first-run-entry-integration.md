## Implemented Boundary

Debug-only `HELM_FIRST_RUN_PRODUCTION_QA=1` selects the real XPC prepared-runtime
path. Research fixtures and Environment Brief fixtures exclude this mode. Release
builds ignore the switch and retain the existing onboarding route.

The presentation controller consumes existing versioned startup/local-observation
contracts, not synthetic research sessions, plans or receipts:

1. Prepare storage without activating adapters, catalogs, polling or self-update
   checks. Fresh and legacy-completed profiles both require the independent
   `wayfinder-v0.20` acknowledgment.
2. When the distribution requires terms acceptance, retain matching recorded GUI
   consent or explicitly present the existing legal gate. The narrow prepared
   FFI endpoint validates the current bundled version, persists it and reads it
   back. It neither completes CLI onboarding nor acknowledges the experience.
3. Present bounded local candidate evidence and clearly mark cached, partial and
   disabled scope. Candidate files are not installation or readiness proof.
4. Only explicit Use Helm Now acknowledges the experience. Re-read the durable
   state and legal version before activation; a success reply alone is not enough.
   The disclosure explains that continuing resumes normal saved behavior,
   including scheduled checks, without authorizing package installation/update.
5. Only successful activation starts ordinary GUI polling/updater availability.
   GUI entry availability is separate from the legacy CLI onboarding Boolean;
   this path does not run legacy onboarding backfill or reset existing settings.

Closing before acknowledgment does not complete the experience. Reconnection
invalidates stale replies. An acknowledged relaunch/RC/stable/patch entry skips
observation, while failed activation remains retryable. Errors do not become an
empty or healthy Environment Brief. Prepared terms-save failures fail closed.

Independent review backports the narrow reply-order correction from #591 into
this entry slice: successful XPC replies join the main queue before checking
connection generation or connection lifetime, and the controller retains its
own generation fence. Three regressions cover background delivery, invalidation
before queued delivery, and valid replies without inline state publication.
The backported slice passes unsigned arm64/macOS 13-target test compilation
and all 395 Swift tests in the disposable macOS VM, including those three cases.
Strict SwiftLint, locale/channel checks, docs-sync and whitespace checks pass.
This automated review evidence does not replace the signed acceptance gates below.

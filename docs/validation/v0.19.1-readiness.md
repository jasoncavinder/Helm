evidence remains separate from publication evidence.

## Maintenance Scope

- [x] Normalize retained older Homebrew kegs into one logical manager installation only when the formula identity and Homebrew prefix match.
- [x] Prefer the active or linked current keg as the representative installation while retaining merged paths as aliases.
- [x] Preserve installations from distinct Homebrew prefixes as separate manageable instances.
- [x] Keep inactive installation rows informational: they do not inherit the active executable's version and cannot initiate manager-wide update or uninstall actions.
- [x] Do not delete old kegs, change Homebrew ownership, redesign manager lifecycle behavior, or include `v0.20.x` work.
- [x] Limit independent-review hardening to release integrity: preflight requires target-tag/Rust-source equality, and the macOS release workflow validates generated app and bundled CLI versions against the tag. These release-only checks do not expand product scope.

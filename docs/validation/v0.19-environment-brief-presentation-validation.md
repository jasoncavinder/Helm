# v0.19 Environment Brief Presentation Validation

Date: 2026-08-08; implementation evidence updated 2026-08-25

## Scope

This checkpoint validates the debug-gated Dashboard-hosted Environment Brief before any production first-run route switch. It covers the versioned `first-useful`, `current`, `partial`, `offline`, and `service-failure` fixtures without accepting legal terms, mutating software, contacting package sources, or using the stable user database.

## Matrix

- All five fixtures rendered at the `860x600` minimum content size and a `1200x800` expanded window size.
- Every size/state combination rendered in deterministic light and dark appearances.
- German, Hungarian, and Japanese rendered in all five states at minimum size in light and dark appearances.
- A temporary copied debug app with every English localization value padded by 40% rendered all five states at minimum size in light and dark appearances.
- The app was built and launched as `arm64` with a dedicated `/tmp` Derived Data directory and an isolated `HELM_DB_PATH` for every launch.

Result: no clipped safety copy, unreachable action, overlap, or contrast-dependent state was found after remediation. The content remains scrollable, expanded layouts preserve the bounded reading width, and localized window titles do not affect fixture operation.

## Findings

### Course Indicator coverage semantics

The partial and service-failure fixtures initially rendered a 100% ring because failed, cancelled, and deferred terminal work counted as mapped coverage. The presentation summary now derives determinate completion from mapped managers only. Regression assertions lock partial coverage to 50%, service failure to 0%, and overlapping observation/failure input to mapped coverage without double counting.

### Text expansion

The 40% expansion pass exposed truncation of the system fact value `Apple silicon`. Environment Brief fact values now support two lines and preserve their intrinsic vertical size. The repeated expansion matrix rendered the full value, and locale-width coverage now budgets actions, statuses, and both trust-strip variants across all supported non-English locales.

## Accessibility Contract Review

- Primary actions are native `Button` controls; `Use Helm Now` and legal acceptance expose the default action keyboard shortcut.
- Decorative symbols are hidden where appropriate, manager and coverage rows combine their visible status text, and the Course Indicator exposes a label plus determinate percentage value.
- State is conveyed by symbol and text in addition to color. Differentiate Without Color adds a dashed ring treatment.
- The Environment Brief defines no custom animation. Native indeterminate progress remains system-owned, so Reduce Motion does not require a parallel custom transition path.
- The header uses one stable semantic subtree and a custom responsive `Layout`, so horizontal and vertical presentation preserve the same accessibility identities rather than replacing the rendered controls.

Owner-assisted VoiceOver and Full Keyboard Access checks were executed after the automated presentation matrix. Basic VoiceOver traversal and keyboard operation passed, but the state title did not appear in the VoiceOver Headings rotor and forward/reverse Full Keyboard Access traversal disagreed within the noninteractive header. On the merged baseline, forward `Tab` stops on the `50%` Course Indicator while reverse `Shift-Tab` skips it.

PR #534 source `2c8726a0` implements the intended correction: the rendered title is a native `GroupBox` label, the Course Indicator remains a separate noninteractive percentage element, and localized Management Readiness rows announce title before count. Responsive-layout and all-locale announcement-order regressions pass, and the full arm64 UI quality gate passes 338 tests with 0 failures.
